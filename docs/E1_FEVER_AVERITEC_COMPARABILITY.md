# FEVER ↔ AVeriTeC Comparability Audit

This document assesses the direct comparability between the FEVER v1.0 dataset (E0) and the AVeriTeC dataset (E1).

## 1. Task Definition
- **FEVER**: Verify short, artificial claims generated by mutating Wikipedia sentences. Evidence is exclusively Wikipedia sentences.
- **AVeriTeC**: Verify real-world claims (e.g., political statements, social media rumors) using multi-hop web retrieval modeled as Question-Answer pairs.

## 2. Claim Structure
- **FEVER**: Short, syntactically simple, highly decontextualized (e.g., "Colin Kaepernick became a starting quarterback during the 49ers' 63rd season.").
- **AVeriTeC**: Often longer, syntactically complex, heavily contextualized, contains temporal markers (e.g., "In a letter to Steve Jobs, Sean Connery refused to appear in an apple commercial.").

## 3. Evidence Structure
- **FEVER**: Flat list of Wikipedia document/sentence IDs.
- **AVeriTeC**: List of `questions`, where each question has an `answers` list containing the `answer` text, `source_url`, and `answer_type`.

## 4. Insufficiency Construction
- **FEVER (`missing_evidence`)**: Artificial. Created by mutating a supported claim (e.g., swapping a name) such that the Wikipedia corpus no longer contains the verifying sentence.
- **AVeriTeC (`retrieved_insufficient`)**: Natural. A real claim for which fact-checkers and web search engines fail to locate definitive proof.

## 5. Comparability Matrix
### Comparable Dimensions
- Both map to a boolean `is_insufficient` verification target.
- Both can be embedded into the same semantic claim-space.

### Non-Comparable Dimensions
- **Evidence Formatting**: FEVER relies on inline sentences; AVeriTeC requires parsing Q&A reasoning paths.
- **Vocabulary/Domain**: FEVER is encyclopedic; AVeriTeC is news/social media. 
- **Insufficiency Origin**: FEVER is artificial manipulation; AVeriTeC is natural scarcity.

## Conclusion
FEVER and AVeriTeC are **not directly comparable** in domain or evidence structure. This makes AVeriTeC an excellent candidate for testing the cross-construction generalization of the claim-space density signal (B3). If a density estimator fitted on FEVER succeeds on AVeriTeC, it demonstrates highly robust generalization.
